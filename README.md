# スイミング記録（PWA版）

子どものスイミングのタイムを記録するPWAです。Muse版スイミング記録と同じ記録形式
（localStorage のキーとJSON構造）を使っています。

## 機能

- 計測：ストップウォッチ（ラップ付き）。測ったタイムをそのまま保存できます
- 記録：手入力でタイムを追加
- 一覧：記録の一覧（ベストにはバッジ表示、削除も可）
- ベスト：種目×距離ごとの自己ベスト（50m以上は短水路／長水路で分割）
- グラフ：種目×距離ごとのタイム推移
- 設定：子どもの名前、JSON書き出し／読み込み、全データ削除

## データについて

- データは端末内（localStorage）にのみ保存されます
- 種目：自由形・背泳ぎ・平泳ぎ・バタフライ・個人メドレー
- 距離：25m / 50m / 100m / 200m（50m以上は短水路／長水路を記録）

## ファイル構成

- `index.html` … アプリ本体
- `manifest.json` … PWA設定
- `sw.js` … Service Worker（オフライン対応）
- `icon-192.png` / `icon-512.png` … アイコン
